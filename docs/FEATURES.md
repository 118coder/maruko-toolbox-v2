## 已知限制（如实记录）
1. GPU 编码器不经过 AVS 管线，AVS 页滤镜仅部分等效支持（D18）。
2. MediaInfo 输出格式与原版 MediaInfo GUI 文本视图一致；ffprobe 回退时格式略有差异。
3. 界面语言首版仅 zh-CN / en。
4. 检查更新需要可用接口；离线时如实报错（D12）。
