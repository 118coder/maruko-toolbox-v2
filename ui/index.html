关于

小丸工具箱V2现代版（V2.0.0）· 在原版 r236 界面与工作流基础上的现代化重实现： GPU 硬件编码（NVENC / QuickSync / AMF 自动探测）、扁平双主题界面、高分屏清晰渲染。 压制行为依赖本机安装的原版小丸工具箱工具链（x264/x265/ffmpeg/MP4Box/MKVToolNix/AviSynth 等），在此向各工具作者致谢。

快速上手（视频压制）

  1. 把视频文件拖到「视频」页第一栏，选择编码器（默认 x265_64-8bit[gcc].exe；有 N 卡可选 HEVC NVENC (GPU) 提速数倍）；
  2. CRF 值越小质量越高（默认 23.5），点「压制」；批量压制把文件加入下方列表后点「压制」；
  3. 内嵌字幕：勾选后选择语言后缀，压制时自动在同目录找 视频名.后缀.ass/srt 烧录；
  4. 「音频模式」= 复制音频流 / 压制音频（用「音频」页参数）/ 无音频流。

各页速览

  • 音频：NeroAAC / qaac / fdkaac / LAME / FLAC 压制，支持批量与合并；
  • 常用：一图流（图片+音频→视频）、无损截取、旋转；
  • 封装：合并为 MP4（MP4Box）/ MKV（mkvmerge）、封装转换（含转 FLV）；
  • 抽取：从任意容器抽取音频/视频流，MKV 用 mkvextract 抽轨道；
  • AVS：滤镜勾选自动生成脚本（也可直接粘贴），预览 / 保存 / 经 avs4x26x 压制；
  • MediaInfo：拖入文件查看完整媒体信息（64 位 MediaInfo.dll 直读）。

提示

  • GPU 编码器不支持 AVS 滤镜管线与 2Pass；需要精细参数请用 x264/x265；
  • 「设置」页可手动指定工具链目录与 ffmpeg 路径；日志在程序目录 logs\；
  • 勾选「自动关机」后批量完成会倒计时 60 秒关机，进度窗可随时取消。
